# Sea of Sand

Minecraft 1.21.1 NeoForge Modpack

## Theme

The world is a vast dried up ocean with small islands. 
It is a mostly-flat, post-apocalyptic world that supports gritty modern weapons and ammo, vehicles, oil and gas, colonists, quests and trading for rare resources, and difficult mobs.

## Development

- Minecraft 1.21.1
- NeoForge
- CurseForge
